# dog starting stance

Generated using the OpenAI built-in image generator with the existing left-facing dog run artwork as the character and style reference. This is a separate grounded quadruped pose for betting, lock, and countdown, with forefeet planted and hind legs poised to launch. Original generated RGBA alpha is preserved in ready/ready_00.png.

ready.json records the exact prompt, source reference, alpha bounds, nose and ground anchors, and display height. The sprite builder crops only transparent margins and packs the starting pose into a spare cell of the existing 1×/2× run sheets. Gameplay switches to the distance-driven run cycle at the start of movement.
