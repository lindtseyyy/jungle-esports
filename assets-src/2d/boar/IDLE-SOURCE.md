# boar subtle upright idle

The standing artwork was generated with OpenAI built-in image generator; see stand.json for the exact prompt and character reference. View direction: front.

A gentle breathing and sway cycle is assembled from that upright sprite using small deterministic pixel deformations. Twenty-four transparent 1336 × 660 frames at 100 ms each form a seamless 2.4-second loop. Chest expansion is at most 0.5%, vertical breathing at most 0.4%, torso sway about 3 pixels, and tail motion 1.2 pixels. Every pixel below row 580 is identical in all frames, so both hind feet stay planted.

Files: idle/idle_00.png through idle/idle_23.png; boar-idle-sheet.png (6 × 4 cells); boar-idle-preview.gif; idle.json. The static standing image is boar-standing.png or stand/stand_00.png. Source assets only; game playback registration is separate.
