# squirrel run cycle

Generated through Higgsfield using Seedream 5.0 Lite with a Seedream 5.0 Flash correction. Final job: 308f1247-c0d2-45aa-a1b8-0225f3b7169d.

Style and motion reference: the existing lion run cycle. The Higgsfield output is preserved as squirrel-run-generated.png. Full prompts and generation IDs are in run.json.

Eleven distinct left-facing running drawings: run/run_00.png through run/run_10.png. Each frame is RGBA with real transparent alpha on a fixed 1336 × 660 canvas, matching the lion canvas. Green backgrounds are keyed and edges despilled. Complete animals are isolated so tails crossing nominal sheet cells are preserved without stray fragments in adjacent frames. A common scale and translation preserve body bounce and motion.

squirrel-run-sheet.png: 4 columns × 3 rows, final cell transparent.
squirrel-run-preview.gif: 11 frames, 50 ms per frame, loops forever; placeholder ground is only in the GIF.

Source assets only. Game playback registration was not changed.
